# Практическая работа №6 — Классификация текстов

## Цель работы

Изучить основные методы обработки текстовых данных и построить модель машинного обучения для классификации отзывов на положительные и отрицательные.

## Используемые инструменты

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
- TF-IDF
- Multinomial Naive Bayes

## Этапы выполнения

### 1. Подготовка данных

Создан датасет с текстовыми отзывами о фильмах и книгах. Каждый отзыв имеет метку класса:

- `positive` — положительный отзыв;
- `negative` — отрицательный отзыв.

### 2. Предобработка текста

Выполнена очистка текстовых данных:

- перевод текста в нижний регистр;
- удаление пунктуации и цифр;
- удаление выбранных стоп-слов;
- подготовка текста к дальнейшей обработке.

### 3. Разделение данных

Данные разделены на обучающую и тестовую выборки с помощью `train_test_split()`.

- 75% данных — обучение модели;
- 25% данных — тестирование модели.

Для предотвращения утечки данных TF-IDF обучается только на тренировочной выборке.

### 4. Векторизация текста

Использован `TfidfVectorizer`, который преобразует текстовые отзывы в числовые признаки. При этом учитывается значимость слов в отдельных документах относительно всего корпуса текстов.

### 5. Обучение модели

Использован классификатор `MultinomialNB` (наивный байесовский классификатор).

Модель обучается на векторизованных отзывах и предсказывает, является ли отзыв положительным или отрицательным.

### 6. Оценка качества

Для оценки модели использованы следующие метрики:

- **Accuracy** — доля правильных предсказаний;
- **Precision** — точность положительных предсказаний;
- **Recall** — полнота положительных предсказаний;
- **F1-score** — гармоническое среднее Precision и Recall;
- **Confusion Matrix** — матрица ошибок классификации.

Также проведён анализ ошибочно классифицированных отзывов.

## Результат работы

В результате создана модель классификации текстов, которая определяет тональность отзывов. Выполнена оценка качества классификации и рассмотрены ошибки модели.

## Файл практической работы

`practical_6_text_classification.ipynb`

В ноутбуке содержатся код, пояснения, результаты вычислений и выводы.

## Вывод

В ходе практической работы изучены этапы предобработки текстовых данных, преобразования текста в числовые признаки с помощью TF-IDF и обучения наивного байесовского классификатора. Для проверки качества модели использованы Accuracy, Precision, Recall, F1-score и матрица ошибок. Отдельное внимание уделено предотвращению утечки данных при подготовке признаков.
